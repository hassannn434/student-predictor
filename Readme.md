# Student Performance Predictor

This is a simple Python project that predicts student performance based on study hours and attendance percentage.

##  Features
- Takes user input for study hours and attendance
- Uses basic logic to calculate performance score
- Displays result as:
  - Excellent
  - Good
  - Average
  - Needs Improvement

##  Technologies Used
- Python
- Conditional Statements
- Functions

##  How to Run
1. Download the file
2. Run:
   python predictor.py

##  Learning Outcome
- Basic Python understanding
- Logic building using conditions
